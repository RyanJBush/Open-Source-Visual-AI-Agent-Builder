# Frozen synthetic comparison

Compare the existing support-v1 keyword rules and local qwen3:4b through the same four-node executor. This set was written by the implementer. It has no customer data. The eight development requests include familiar smoke-test scenarios. The 24 new held-out requests are interleaved across the four categories, six per category. They include literal keyword matches and paraphrases. The sample does not estimate a production distribution.

**Freeze before scoring.** Commit both splits, answer keys, scoring script, existing model instruction, workflow template and keyword rules before running the held-out split. Run development first. Do not change the prompt, rules, labels, or cases in response to held-out results. Use the recorded split only once for the reported comparison. A later rerun is a reproducibility check.

**Label policy.** Billing covers transactions, invoices, receipts and refunds. Account covers identity and access recovery. Technical covers product malfunctions outside access recovery. Other covers general information and pre-sales questions. A question about discount availability before purchase is other. A password-reset malfunction is account under this policy. Each case has one expected label. The model receives the fixed label vocabulary plus the request in its template; expected answers, record IDs and keys stay outside inference.

**Procedure.** Score serially in file order, one keyword execution followed by one Ollama execution per request. Use the committed templates and qwen3:4b settings (temperature 0, seed 0). No retries or selection of the best output. Measure monotonic wall time around each complete executor invocation, including local model HTTP for Ollama. Report median and nearest-rank p95 across all attempts. Run on the same workstation. Model load state can affect latency.

**Accounting.** Correct / total uses all cases, including invalid replies and execution failures. Unreadable, oversized and out-of-vocabulary provider responses count as invalid. Refusal, timeout and transport errors count as execution failures. The four-label contract has no abstention response, so abstentions are zero by design. Other is a scored category. No paid provider is used; dollar cost and electricity are unmetered. Per-case results, model identity and software fingerprints accompany the summary.
